Organisasi Mahasiswa

Website organisasi mahasiswa yang dibuat sebagai mini project pembelajaran HTML, CSS, dan Git.

Deskripsi

Website ini menyediakan informasi mengenai organisasi mahasiswa, program kegiatan, serta informasi kontak. Website terdiri dari beberapa halaman yang saling terhubung dan menggunakan CSS untuk mengatur tampilan. "website ini masih sangat jauh dari sempurna jadi saya mohon untok komentar dari bapak dosen. Terima kadih"

Teknologi yang Digunakan

- HTML
- CSS
- Git
- GitHub

Halaman Website

- Beranda — halaman utama website.
- About — informasi mengenai organisasi.
- Program — informasi program/kegiatan organisasi.
- Kontak — informasi kontak organisasi.
