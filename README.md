# Website Profil Organisasi Mahasiswa

## Deskripsi
Website Profil Organisasi Mahasiswa yang dibuat sebagai mini project untuk menampilkan informasi mengenai organisasi, program, dan kontak.

## Tujuan dan Fitur
Website bertujuan memberikan informasi mengenai organisasi mahasiswa kepada pengguna.

Fitur utama:
- Profil organisasi
- Program dan kegiatan
- Informasi kontak

## Struktur Folder
- `assets/` — menyimpan CSS dan gambar
- `pages/` — menyimpan halaman tambahan
- `index.html` — halaman utama
- `README.md` — dokumentasi proyek
- `.gitignore` — mengatur file yang tidak dilacak Git

## Cara Menjalankan
Buka file `index.html` menggunakan browser.
